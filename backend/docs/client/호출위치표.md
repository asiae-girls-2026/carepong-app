# 앱 → 서버 호출 위치 표 (연우·채원 작업용) — 2026-10-02, 명세 v5.1

`docs/client/api.js` 를 `core/` 옆에 두고, 아래 "앱 동작"이 일어나는 자리에서 "호출" 한 줄을 넣는다.
즉시 전송은 ★ 2개뿐. 나머지는 `logEvent` 로 로컬에 쌓이고 08:30/앱 시작 시 자동 전송.

## A. 앱 생애주기

| 앱 동작 | 호출 | props |
|---|---|---|
| 앱 시작 (CP 번호 발급 직후) | `await api.init({cpNumber, deviceId, appVersion, dataDir})` | — |
| 앱 시작 | `api.logEvent("app_start", null, {prev_clean_exit, os, version})` | |
| 5분마다 | `api.logEvent("heartbeat", null, {})` · `api.logEvent("app_health", null, {cpu, mem, events_dropped, crash})` | |
| 종료 직전 | `api.logEvent("app_quit", "P01", {src: "menu"\|"tray", hour})` → `await api.flushEvents()` | |

## B. 감지 (★ 실시간)

| 앱 동작 | 호출 | 비고 |
|---|---|---|
| ★ 수집기 stdout 에서 1분 창 1줄 받을 때 | `const r = await api.postWindow({sessionId, windowStart, features, dnd, appTab})` | 활동 0 창도 보냄. `appTab` = 그 1분 동안 열려 있던 우리 앱 화면(`pet`/`mind`/`archive`/`settings`/null). `r.prompt === true` 면 P03 팝업, `r.prompt_type` 저장 |
| P03 팝업 노출 | `api.logEvent("stress_prompt_shown", "P03", {index: r.condition_score, nth_today})` | |
| ★ [예]/[아니요] 누름 · 닫기 · 다른 곳 클릭 · 응답 없이 다음 팝업 시각 | `await api.postSelfReport({windowId: r.window_id, trigger: r.prompt_type, yesno: 1\|0\|null, status: "answered"\|"dismissed"\|"ignored"\|"pending", promptTime, clickedAt})` + `api.logEvent("stress_prompt_answered", "P03", {answer, latency_ms})` | 팝업은 자동으로 안 닫힘. 네 상태 중 하나로 **반드시 한 번** 보냄. `promptTime` = 팝업 뜬 시각 저장해 둘 것 |
| [예] 후 1~5 선택 | `await api.postSelfReport({windowId, trigger: r.prompt_type, yesno: 1, level1to5: n})` + `api.logEvent("stress_score_answered", "P03", {score: n})` | 위 호출을 1~5까지 받은 뒤 한 번만 보내도 됨 |
| 정기 체크인 (앱 자체 일정) | `await api.postSelfReport({trigger: "checkin", yesno, level1to5})` | window_id 없음 |

## C. 알람 (P02) — 로컬 큐

| 앱 동작 | 호출 |
|---|---|
| 말풍선 노출 | `api.logEvent("alarm_shown", "P02", {kind: "med"\|"water"\|"stretch"\|"rest"})` |
| [먹었어요/마셨어요/했어요/쉬었어요] · [나중에] · 45초 무응답 | `api.logEvent("alarm_answered", "P02", {kind, answer: "confirm"\|"later"\|"timeout"})` |

## D. 펫·완화·미니홈 — 로컬 큐

| 앱 동작 | 호출 |
|---|---|
| 밥·쓰다듬기·산책 | `api.logEvent("care_action", "P01", {type: "feed"\|"pet"\|"walk"})` |
| 기력<20 산책 거부 | `api.logEvent("care_action", "P01", {type: "walk_refused"})` |
| 방해금지 켜기/끄기 | `api.logEvent("dnd_toggle", "P08", {on, src: "menu"\|"tray"\|"schedule", hour})` |
| 완화 메뉴에서 선택 | `api.logEvent("relief_selected", "P04", {type: "breath"\|"meditate"\|"chat", entry: "stress_prompt"\|"mind_tab", window_id, report_id})` — Route1(감지 팝업)이면 `window_id`·`report_id` 넣기 (혜윤: 과부하→완화 연결). Route2(1분 쉬어가기)는 둘 다 null, `chat` 없음 |
| 심호흡 3회·명상 90초 완료 | `api.logEvent("relief_completed", "P04"/"P05", {type, dur_ms})` |
| 중단·ESC | `api.logEvent("relief_abandoned", "P04"/"P05", {type, step})` |
| 레벨업 / 이름짓기 / Lv5→다음 캐릭터 | `api.logEvent("level_up", "P06", {level})` · `("rename", "P07", {})` · `("rebirth", "P07", {generation})` |
| 기분 버튼 / 메시지 전송 | `api.logEvent("mood_checked", "M05", {mood})` · `("chat_message", "M05", {len, keyword_hit})` |
| 미니홈 탭 진입 / 미니홈 닫기 | `api.logEvent("tab_opened", "M01", {tab: "mind"\|"archive"\|"settings"})` · `api.logEvent("minihome_closed", "M01", {})` — 체류시간 계산용 |
| 방꾸미기 단계 올라갈 때 | `api.logEvent("furniture_unlocked", "M01", {stage})` — 하트는 이벤트 없음(메시지 수로 산출). 누적 하트·단계는 `putPet` 스냅샷으로 |
| 약 등록 시작/완료/이탈 | `api.logEvent("med_register_started"/"_completed"/"_abandoned", "M07", {path: "lui"\|"gui", dur_ms, step})` |
| 수집 일시중지 토글 / 물 목표 변경 | `api.logEvent("collector_toggle", "M07", {on})` · `("water_goal_changed", "M07", {goal, interval})` |

## E. 백업 (바뀔 때, 실패 무시)

| 앱 동작 | 호출 |
|---|---|
| 설정 저장 | `api.putRoutines({water_goal_cups, water_interval_min, stretch_interval_min, rest_interval_min, dnd_schedule_enabled, dnd_start, dnd_end, pet_opacity, pet_motion_minimal})` |
| 약 등록·수정·삭제 | `api` 에 아직 없음 — 10/5 추가 예정 (`postMedication` 등). 1차는 로컬만으로도 됨 |
| 펫 상태 변동 (레벨업·환생·하트 등) | `api.putPet({name, character_slot, generation, level, xp, happiness, health, energy, hearts_total, furniture_stage, updated_at})` |

## 규칙

- 이벤트명·props 키는 채원 마커 표 그대로. 서버가 모르는 이름은 `rejected_ids` 로 돌려주고 저장 안 됨
- 원시 키 코드·텍스트·창 제목은 어디에도 넣지 않음
- 수집기는 08:30~18:30 (방해금지 밖)에만 돌림 — Electron 이 `collector.exe` 를 그 시간에 켜고 끔
- 서버 주소: 로컬 테스트 `http://localhost:8000`, AWS 올라가면 `CAREPONG_API` 환경변수로 교체
