# 내 펫 — 게임 로직 / 수치 정리

모든 스탯은 **0~100**. 핵심 코드: `src/core/config.ts`, `src/core/stats.ts`, `src/core/lifecycle.ts`, `src/core/social.ts`, `src/renderer/App.tsx`.

## 1. 스탯 3종
| 스탯 | 자연 감소(시간당) | 비고 |
| --- | --- | --- |
| 행복 🩷 | **−3.5 / 시간** | 가장 빨리 닳음 |
| 건강 💪 | **−2 / 시간** | 죽음과 직결 |
| 기력 ⚡ | **−2 / 시간** | 회복 수단: 물·휴식 |

- 감소는 **앱이 꺼져 있어도** 누적(다시 켤 때 경과 시간만큼 한 번에 반영).
- 외형 표현: 행복<40 → 시무룩, 기력<30 → 졸림(외형만, 죽음과 무관).

## 2. 스탯 증감(행동별)
| 행동 | 효과 |
| --- | --- |
| 먹이주기 🍙 | 행복 **+20**, 건강 **+15** |
| 먹이주기 과식(최근 1시간 4회 이상) | 추가로 기력 **−8** |
| 물마시기 💧 (알림 확인) | 기력 **+12**, 건강 **+4** |
| 복약 확인 💊 (알림 확인) | 건강 **+10**, 행복 **+5** |
| 복약 놓침 (알림 무시) | 건강 **−8**, 행복 **−5** (+순응률 하락) |
| 산책 종료 🚶 | 행복 **+10**, 기력 **−15** (지침) |
| 뽀뽀 💋 | 행복 +8 / 친밀도 +5 |
| 껴안기 🤗 | 행복 +8 / 친밀도 +4 |
| 쓰다듬기 🖐️ (친구 없을 때) | 행복 +6 |
| 밤·방해금지(휴식) 중 | 기력 **+4 / 1분(틱)** 회복 |
| 외출(친구집) 중 | 감소 **0.25배** + **35 미만으로 안 떨어짐**(안 죽음, 성장 X) |

## 3. 상태 단계 (건강 기준)
| 건강 | 상태 |
| --- | --- |
| > 30 | 건강함 😊 |
| ≤ 30 | 아픔 🤒 |
| ≤ 10 | 위독 🚨 |
| 위독 **48시간 지속** | 죽음 🌈 → 추모 → 새 알 환생(이름 다시) |

- 상태 진입 시 **맥 알림 + 말풍선** 자동.

## 4. 성장 (5단계)
부화 후 **누적 성장일**로 단계 상승. 도달 일수: **1 / 8 / 14 / 20일**.
| 단계 | 도달(누적 성장일) |
| --- | --- |
| 1단계 | 부화 직후 |
| 2단계 | 1일 |
| 3단계 | 8일 |
| 4단계 | 14일 |
| 5단계 | 20일 |

- **성장 가속**: 건강 ≥ 60 **그리고** 행복 ≥ 60 인 동안엔 성장일이 **×1.6배**로 빨리 쌓임 → 잘 돌볼수록 빨리 큼.
- 레벨업 시 ✨반짝임 효과 + 안내.

## 5. 알림
- **복약**: 등록한 시간(요일) 도래 시. **물**: 설정 간격(**최소 20분**)마다 + 하루 목표 컵까지.
- **방해금지/밤**: 알림 멈춤 + 펫 수면 + 기력 회복.
- **나중에** → 10분 뒤 재알림. **무응답 45초** → 자동 사라짐(복약이면 ‘놓침’ 처리).
- 기력 0 → "물·비타민 챙겨 기력 올려보세요" 안내 1회.

## 6. 친밀도 (친구별, 0~100)
| 행동 | 친밀도 |
| --- | --- |
| 놀러오기 수락 | +8 |
| 쓰다듬기(게스트) | +5 |
| 뽀뽀 | +5 |
| 껴안기 | +4 |
| 펫 보내기(외출) | +5 |
| 교배 실패 | +6 (위로) |

## 7. 교배
- **조건**: 내 펫이 **5단계**일 때만.
- **성공 확률** = `40% + (친밀도 ÷ 100) × 60%`
  - 친밀도 0 → **40%**, 50 → **70%**, 100 → **100%**
- **실패**: 아기 없음, 친밀도 +6.
- **성공**: 자식 = **부모 합성종**(`base_x_partner` 아트), 1단계, 세대 = max(부모 세대)+1.
- **희귀 교배종**: **15% 확률**로 일반 파트너 대신 희귀종(여우·해달·토끼·유니콘·나르왈·드래곤·부엉이) 합성으로 출생. 해당 base 아트가 없으면 부모종으로 폴백.
- 현재 합성 base 아트: **쿼카·도마뱀·우파루파** (나머지 9종 base 시트 추가 시 동일 적용).
