# 케어퐁 IA (2026-09-28 개편)

## 레퍼런스에서 딴 것

| 출처 | 차용 요소 | 케어퐁 적용 |
|---|---|---|
| 싸이월드 미니홈피 | "OO의 미니홈피" 문패, 미니미+미니룸(좌상단 캐릭터·방), 우측 책갈피(폴더) 탭, TODAY 표시, 파스텔+이중 프레임+둥근 버튼 | 상단 "{펫이름}의 미니홈" + TODAY 기분 배지 / 미니룸(벽지·창문·나무바닥·러그) 안에 펫 / 우측 세로 책갈피 탭(약지도·마음관리) / 하늘색+주황 팔레트, 박스 안 박스 프레임 |
| 다마고치·펫 육성 게임 | 돌봄 버튼·상태 게이지·픽셀 캐릭터 | 오버레이 우클릭 돌봄 3종, 상태확인 게이지 카드, image-rendering: pixelated 스프라이트 |

## 구조

```
케어퐁
├─ 바탕화면 오버레이 (펫)
│   ├─ 돌봄(우클릭): 밥 주기 / 쓰다듬기 / 산책
│   ├─ 알람 말풍선 4종: 약·물·스트레칭·휴식 (확인형)
│   ├─ 스트레스 완화 프롬프트 → 심호흡·명상 (게이지 노출 없음)
│   ├─ 성장·레벨업 / 만렙 환생 프롬프트
│   └─ 우클릭(간소화): 돌봄 3종 │ 미니홈 🏠 │ 방해금지 │ 종료
│
├─ {펫이름}의 미니홈 (챗 창 420×640) ★ 허브
│   ├─ 상단 바: "{이름}의 미니홈" + TODAY 기분
│   ├─ 미니룸: 픽셀 방 + 펫(집주인) + 문패(Lv·세대)
│   ├─ 💊 약지도 (책갈피 탭)
│   │   ├─ 오늘의 복약 체크리스트 (n/m 완료 · 먹었어요 버튼)
│   │   ├─ 약 등록 2경로: [💬 말로 등록](LUI 위저드+한 줄 명령) / [📝 폼으로 등록](GUI)
│   │   │     └ 두 경로 소요시간 자동 계측 → 비교 테스트 (docs/테스트설계_LUI_vs_GUI_약등록.md)
│   │   ├─ "오늘 약 보여줘" 조회
│   │   └─ 약 이름 Q&A (e약은요 + 목업)
│   ├─ 💛 마음관리 (책갈피 탭)
│   │   ├─ TODAY 기분 체크 5종 (ESM — 상단 배지 연동)
│   │   ├─ 공감 대화 (상호 돌봄형 존댓말 · 위기 안전 레이어)
│   │   └─ 칩[1분 쉬어가기] → 오버레이 완화 실행
│   └─ ⚙️ 설정 (책갈피 탭 — 별도 창 없음, 미니홈 통합)
│       ├─ 알람 간격: 물 목표/간격 · 스트레칭 · 휴식
│       ├─ 방해금지 시작/끝 · 펫 움직임 최소화 · 등록된 약 관리(삭제)
│       ├─ QA·데모: XP·만렙·환생·회복·시무룩 · 스트레스 시뮬레이션
│       └─ 약 등록 테스트 기록 (LUI/GUI 평균·최근 기록·초기화)
```

## LUI 설계 결정

- 자유 파싱 단독은 오인식이 많다 → **가이드 위저드(이름→시간)를 기본**, 한 줄 명령(`{이름} {아침|저녁|21:30} 등록`)은 보조.
- 시간 어휘: 아침 09:00 / 점심 13:00 / 저녁 19:00 / 자기 전 22:00 / 공복·기상 07:00 / `N시`·`HH:MM` (점심 중심 정책은 패널과 동일).
- 미니홈에서 등록·체크한 것은 오버레이 알람과 같은 저장소(config·intake)를 씀 — 체크하면 알람 중복 발송 안 됨, 순응률 동일 반영.
- LLM 연동 시: 파서(core/medLui.ts)를 tool-calling으로 교체하면 자연어 전반 커버 가능(교체 지점 주석 있음).
