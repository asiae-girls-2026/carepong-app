# 필리몽 캐릭터 디자인·애니메이션 에셋 규칙

- 작성일: 2026-07-12
- 적용 범위: 기본 캐릭터, 성장 단계, 상태·행동 애니메이션, 교배종
- 상태: 1차 디자인 방향 승인

## 1. 목표

필리몽의 캐릭터는 작은 화면에서 바로 알아볼 수 있고, 먼저 돌보고 싶다는 감정을 일으켜야 한다. 캐릭터 수를 늘리기보다 완성도 높은 기본 캐릭터 2종을 먼저 제작한다.

기존의 12종 동물과 36종 교배종 에셋은 새 디자인 체계의 기준으로 사용하지 않는다. 새 에셋은 이 문서의 규격에 따라 별도 제작하며, 기존 파일의 삭제와 코드 교체는 새 에셋 검증 이후에 진행한다.

## 2. 세계관과 캐릭터 방향

### 2.1 공통 세계관

- 캐릭터는 꿈에서 태어나 돌봄을 받으며 성장하는 `꿈 정령`이다.
- 실제 동물을 그대로 재현하지 않고, 귀여운 동물의 특징을 꿈·달·별 모티프로 번역한다.
- 성별을 외형으로 구분하지 않는다.
- 건강 습관을 잘 지킬수록 꿈의 빛과 무늬가 선명해진다.

### 2.2 기본 캐릭터 A: 쿼카형 꿈 정령

- 핵심 인상: 포근함, 친근함, 안아주고 싶은 느낌
- 체형: 둥근 머리와 몸, 통통한 볼, 짧은 팔다리
- 고유 실루엣: 둥근 귀, 구름 모양 꼬리
- 표정: 자연스럽게 올라간 입꼬리
- 성격: 다정하고 느긋함
- 꿈 상징: 달, 포근한 잠, 베개
- 기본 색상 방향: 크림, 라벤더, 연한 남색

### 2.3 기본 캐릭터 B: 우파루파형 꿈 정령

- 핵심 인상: 엉뚱함, 호기심, 신비로움
- 체형: 넓은 얼굴과 짧은 팔다리
- 고유 실루엣: 머리 양옆의 별 모양 꿈 촉수, 물결 꼬리
- 표정: 멍하고 순한 표정
- 성격: 호기심이 많고 엉뚱함
- 꿈 상징: 별, 자각몽, 꿈속 여행
- 기본 색상 방향: 연분홍, 하늘색, 짙은 보라

### 2.4 공통 골격 원칙

두 캐릭터는 외형은 다르지만 애니메이션 제작을 위해 다음 기준을 공유한다.

- 몸통 높이와 눈의 기준 위치
- 팔 2개, 다리 2개의 관절 위치
- 바닥선과 몸의 중심축
- 행동별 프레임 수와 재생 속도
- 손이 닿는 위치와 먹이의 진입 방향

귀, 꿈 촉수, 꼬리, 무늬와 빛 효과는 별도 보조 파츠로 취급한다.

## 3. 성장 단계 규칙

게임 로직의 성장 단계 1\~5는 유지하되, 애니메이션 골격은 3종만 제작한다.

| 성장 단계 | 사용 골격 | 외형 차이 |
| --- | --- | --- |
| 1단계 | `baby` | 작은 꿈의 핵, 짧은 팔다리, 무늬 없음 |
| 2단계 | `baby` | 귀·촉수 발아, 약한 빛 효과 |
| 3단계 | `child` | 종별 실루엣 확립, 꼬리 등장 |
| 4단계 | `adult` | 상징 파츠 성장, 별자리 무늬 등장 |
| 5단계 | `adult` | 수호 정령 완성, 빛과 장식 강화 |

단계 차이는 몸을 무조건 크게 그리는 방식보다 다음 요소로 표현한다.

- 머리와 몸의 비율
- 귀·꿈 촉수·꼬리의 크기
- 꿈의 핵 형태
- 별자리 무늬의 수와 복잡도
- 주변 빛 입자

1\~2단계와 4\~5단계는 같은 골격을 사용하되 각 단계의 최종 PNG 프레임은 별도로 출력한다. 앱 실행 중 파츠를 조합하지 않고 완성 프레임을 재생하는 것을 기본으로 한다.

## 4. 픽셀아트 제작 규격

### 4.0 귀여움 디자인 문법

모든 기본종과 교배종은 다음 공통 디자인 문법을 사용한다. 이 규칙은 유아·키즈 마스코트에서 반복되는 시각 원리를 분석해 필리몽의 꿈 정령 세계관에 맞게 재구성한 것이며, 다른 작품의 고유 캐릭터나 장식을 복제하지 않는다.

#### 얼굴과 비율

- 머리는 전체 키의 55\~65%를 차지한다.
- 눈은 얼굴에서 가장 강한 요소이며, 눈 사이 간격은 눈 하나 너비 안팎으로 둔다.
- 눈·코·입은 얼굴 아래쪽에 모으고 눈과 입 사이 거리를 짧게 유지한다.
- 눈의 바탕은 검정에 가까운 색을 사용한다.
- 눈 아래쪽 20\~30%에만 캐릭터의 속성색을 넣을 수 있다.
- 각 눈에는 큰 흰색 하이라이트 1개와 작은 하이라이트 1\~2개를 사용한다.
- 볼터치는 눈 아래 바깥쪽에 넓게 두고, 입은 작지만 감정이 분명하게 읽혀야 한다.
- 목은 표시하지 않거나 최소화한다.

#### 몸과 실루엣

- 몸통은 머리보다 작고 원형, 물방울형 또는 콩 모양으로 단순화한다.
- 팔과 다리는 짧고 손가락·발가락 표현을 생략한다.
- 기본 자세는 정면에 가까운 3/4 자세를 사용한다.
- 캐릭터가 달라도 눈 기준선, 어깨·골반 앵커와 바닥선은 공유한다.
- 각 캐릭터는 축소된 흑백 실루엣에서도 식별되는 대표 파츠를 정확히 하나 가진다.

#### 색 역할

한 캐릭터의 색은 다음 비율을 기준으로 역할을 분리한다.

- 주색 약 60%: 몸의 기본색
- 보조색 약 25%: 그림자, 귀·촉수·꼬리
- 강조색 약 10%: 눈 하단, 무늬, 상징 파츠
- 최종 진화 포인트 약 5%: 별빛 노랑 또는 금색

여러 색을 몸 전체에 균일하게 흩뿌리지 않는다. 얼굴은 단순하게 유지하고 머리 주변, 꼬리와 가슴 상징을 중심으로 색을 확장한다.

#### 테마 구성 공식

```text
공통 꿈 정령 몸체 + 생물의 귀여운 특징 1개 + 꿈 테마 1개 + 대표색 + 상징 파츠 1개
```

- 쿼카형: 포근한 볼과 체형 + 달잠 + 크림·라벤더 + 반달 감각기관
- 우파루파형: 넓고 순한 얼굴 + 별꿈 + 핑크·블루 + 별 모양 꿈 촉수
- 교배종: 부모 파츠를 모두 붙이지 않고 새로운 통합 상징 하나로 번역한다.

#### 성장에 따른 색 개화

| 단계 | 색과 장식 변화 |
| --- | --- |
| 1단계 | 주색과 보조색 중심, 장식 없음 |
| 2단계 | 볼과 감각기관에 첫 포인트색 등장 |
| 3단계 | 눈 하단 속성색, 꼬리 무늬와 가슴 상징 추가 |
| 4단계 | 대비색과 별자리 패턴 추가 |
| 5단계 | 금색·보석색·꿈빛 추가, 얼굴의 단순함은 유지 |

5단계에서도 기본 몸색과 대표 실루엣은 유지하여 같은 캐릭터의 성장으로 읽히게 한다.

### 4.1 캔버스

- 모든 원본 프레임의 논리 캔버스: `128 × 128 px`
- 배경: 완전 투명
- 바닥선: `y = 112 px`
- 중심축: `x = 64 px`
- 캐릭터는 그림자 없이도 바닥선에 안정적으로 서 있어야 한다.
- 동작 중 파츠가 캔버스를 벗어나지 않도록 좌우·상단 안전 여백을 둔다.
- 앱에서는 정수 배율 또는 최근접 보간으로 확대한다.

### 4.2 픽셀 표현

- 안티앨리어싱을 사용하지 않는다.
- 반투명 픽셀은 꿈빛·입자 효과에만 제한적으로 사용한다.
- 외곽선 굵기는 같은 성장 골격 안에서 일관되게 유지한다.
- 작은 화면에서 눈과 입이 뭉개지지 않도록 얼굴 핵심 픽셀을 우선한다.
- 캐릭터별 기본 팔레트는 투명색을 제외하고 16색 이내를 권장한다.
- 좌우 걷기는 기본적으로 한 방향만 제작하고 앱에서 좌우 반전한다.
- 글자, 숫자, 의미 있는 비대칭 문양은 좌우 반전 대상 파츠에 사용하지 않는다.

### 4.3 기준 레이어

Aseprite 원본은 다음 레이어 순서를 사용한다.

1. `guide` — 중심축, 바닥선, 안전 영역. 출력 제외
2. `fx_back` — 뒤쪽 꿈빛과 입자
3. `tail_back` — 몸 뒤 꼬리와 촉수
4. `body` — 몸통과 팔다리
5. `face` — 눈, 입, 볼
6. `feature_front` — 앞쪽 귀, 촉수, 장식
7. `fx_front` — 앞쪽 빛과 효과

레이어 이름은 영문 소문자와 밑줄만 사용한다.

## 5. 애니메이션 장면 목록

### 5.1 기본 동작 세트

| ID | 장면 | 프레임 수 | 반복 | 제작 기준 |
| --- | --- | ---: | --- | --- |
| `idle` | 기본 대기 | 4 | 반복 | 호흡, 귀·촉수의 미세 움직임 |
| `blink` | 눈 깜빡임 | 2 | 1회 | 기본 자세와 위치 고정 |
| `walk` | 걷기 | 6 | 반복 | 뒤뚱거림, 바닥선 고정 |
| `eat` | 먹기 | 6 | 1회 | 먹이를 보고 받아먹는 흐름 |
| `pet` | 쓰다듬기 반응 | 5 | 1회 | 손이 오는 방향으로 기울고 행복해함 |
| `sleep` | 잠자기 | 3 | 반복 | 웅크림과 느린 호흡 |
| `happy` | 기쁨 | 4 | 1회 | 성장·복약·물 마시기 성공 |
| `sad` | 슬픔 | 2 | 반복 | 표정과 자세 변화, 색상 필터에 의존하지 않음 |
| `sick` | 아픔 | 2 | 반복 | 몸이 처지고 빛이 약해짐 |
| `critical` | 위독 | 2 | 반복 | 약한 떨림, 과도하게 공포스럽지 않게 표현 |
| `dead` | 잠든 잔상 | 1 | 정지 | 추모 화면으로 자연스럽게 연결 |

캐릭터 1종, 성장 골격 1종의 전체 동작 세트는 총 37프레임이다.

### 5.2 1차 검증 세트

전체 제작 전에 한 캐릭터의 한 성장 골격으로 다음 22프레임을 먼저 검증한다.

- 기본 자세 1장
- `idle` 4프레임
- `walk` 6프레임
- `eat` 6프레임
- `pet` 5프레임

검증 항목은 다음과 같다.

- 실제 데스크톱 표시 크기에서 얼굴이 읽히는가
- 좌우 이동 중 발이 미끄러져 보이지 않는가
- 먹이와 손이 캐릭터의 얼굴·몸에 자연스럽게 닿는가
- 귀·꿈 촉수·꼬리의 움직임이 실루엣을 방해하지 않는가
- 투명 배경 가장자리에 잔여 픽셀이 없는가

이 검증을 통과한 뒤 두 번째 캐릭터, 나머지 골격, 상태 동작 순으로 확장한다.

## 6. 교배종 디자인 규칙

교배종은 부모 동물의 신체를 직접 접합하지 않는다. 부모 특징을 꿈 정령의 상징 언어로 번역한다.

| 부모 특징 | 교배종 표현 |
| --- | --- |
| 쿼카형 둥근 귀 | 머리 위 반달 또는 별 장식 |
| 우파루파형 촉수 | 빛나는 꿈 촉수 또는 후광 |
| 구름 꼬리 | 반달·물결이 섞인 꼬리 |
| 몸 색상 | 두 팔레트에서 주색 1개와 보조색 1개 계승 |
| 무늬 | 부모의 꿈 상징을 별자리 패턴으로 조합 |

교배종 제작 원칙은 다음과 같다.

- 부모 중 한 종의 공통 골격을 기준으로 선택한다.
- 머리 실루엣을 결정하는 고유 파츠는 최대 2종만 사용한다.
- 귀와 촉수를 그대로 모두 붙이지 않는다.
- 색은 두 부모 팔레트를 반씩 섞지 않고 주색과 보조색의 역할을 분리한다.
- 눈과 입의 위치는 공통 골격 기준을 유지한다.
- 교배종도 같은 11개 동작 ID와 프레임 수를 사용한다.
- 실루엣을 흑백으로 보았을 때 하나의 생명체처럼 읽혀야 한다.

## 8. 파일명 규칙

### 8.1 캐릭터 ID

- 영문 소문자 kebab-case를 사용한다.
- 기본종: `quokka-dream`, `axolotl-dream`
- 교배종: 부모 ID를 `_x_`로 연결한다.
- 교배 순서는 게임에서 정한 정규 순서를 사용하여 중복 생성을 막는다.

예시:

```text
quokka-dream_x_axolotl-dream
```

### 8.2 스프라이트시트

앱용 기본 출력은 동작별 가로 스프라이트시트 PNG다.

```text
<action>.png
```

예시:

```text
idle.png
walk.png
eat.png
pet.png
```

각 셀은 `128 × 128 px`이며 프레임은 왼쪽에서 오른쪽 순서로 배치한다. 시트 전체 크기는 `128 × 프레임 수` 너비와 `128 px` 높이를 사용한다.

검수용 개별 프레임이 필요한 경우에만 다음 형식을 사용한다.

```text
<action>-<frame 2자리>.png
walk-01.png
walk-02.png
```

## 9. 애니메이션 메타데이터

각 캐릭터 폴더에는 `manifest.json`을 둔다. 모든 캐릭터가 같은 동작 ID를 사용하고, 속도만 필요한 범위에서 조정한다.

```json
{
  "id": "quokka-dream",
  "canvas": { "width": 128, "height": 128 },
  "groundY": 112,
  "animations": {
    "idle": { "frames": 4, "fps": 4, "loop": true },
    "blink": { "frames": 2, "fps": 8, "loop": false },
    "walk": { "frames": 6, "fps": 8, "loop": true },
    "eat": { "frames": 6, "fps": 8, "loop": false },
    "pet": { "frames": 5, "fps": 8, "loop": false },
    "sleep": { "frames": 3, "fps": 2, "loop": true },
    "happy": { "frames": 4, "fps": 8, "loop": false },
    "sad": { "frames": 2, "fps": 2, "loop": true },
    "sick": { "frames": 2, "fps": 2, "loop": true },
    "critical": { "frames": 2, "fps": 6, "loop": true },
    "dead": { "frames": 1, "fps": 1, "loop": false }
  }
}
```

## 10. 원본·출력 형식

- 편집 원본: `.aseprite`
- 앱용: 투명 배경 PNG 스프라이트시트
- 검수용: 개별 PNG 프레임 또는 GIF
- 포트폴리오 미리보기: GIF 또는 애니메이션 WebP
- 앱에서는 GIF를 직접 재생하지 않는다.

GIF는 색상과 반투명 표현에 제한이 있으므로 꿈빛, 그림자와 입자 효과의 최종 품질 기준으로 사용하지 않는다.

## 11. 제작 순서

1. 두 캐릭터의 흑백 실루엣과 정면 기본 자세를 비교한다.
2. 쿼카형 또는 우파루파형 중 한 종을 선택해 `adult` 골격의 1차 검증 세트 22프레임을 제작한다.
3. 실제 앱에서 표시 크기, 이동, 먹이와 쓰다듬기 위치를 검증한다.
4. 기준을 보정한 뒤 두 번째 캐릭터의 같은 검증 세트를 제작한다.
5. 두 캐릭터의 `baby`, `child` 골격으로 확장한다.
6. 슬픔, 아픔, 위독, 죽음 등 상태 동작을 추가한다.
7. 두 기본 캐릭터가 완성된 뒤 첫 교배종을 제작한다.
8. 모든 에셋과 코드 전환이 확인된 뒤 기존 에셋의 보관 또는 삭제를 결정한다.

## 12. 완료 체크리스트

- [ ] 캐릭터 ID와 폴더명이 규칙에 맞는다.
- [ ] 모든 프레임이 128 × 128 px 셀을 사용한다.
- [ ] 중심축과 바닥선이 동작 사이에서 흔들리지 않는다.
- [ ] 투명 배경 가장자리에 잔여 픽셀이 없다.
- [ ] 안티앨리어싱이 섞이지 않았다.
- [ ] 좌우 반전 시 어색한 비대칭 요소가 없다.
- [ ] 동작 ID, 프레임 수, 반복 설정이 manifest와 일치한다.
- [ ] 실제 앱 표시 크기에서 눈·입과 고유 실루엣이 읽힌다.
- [ ] 교배종이 신체 접합처럼 보이지 않는다.
- [ ] GIF가 아닌 PNG 스프라이트시트를 앱용 원본으로 제공했다.
