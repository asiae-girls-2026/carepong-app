# 데스크탑 펫 건강 도우미 — 설계 문서

- **작성일**: 2026-06-11
- **작성자**: 박채원 (PM)
- **상태**: 설계 승인 대기

## 1. 한 줄 정의

내 맥 바탕화면을 돌아다니며 복약·수분 섭취 등 건강습관을 챙겨주는, 다마고치처럼
"살아있는" 데스크탑 펫. 잘 챙기면 자라고 행복해지고, 방치하면 시들고 끝내 죽는다.

## 2. 목표 & 성격

- **실사용**: 작성자 본인이 매일 실제로 사용한다.
- **배포**: 일반 사용자에게 배포해 쓰게 한다.
- **포트폴리오**: 헬스케어 도메인 전환을 보여줄 기획·행동변화(넛지) 설계 사례.

## 3. 범위 (Scope)

### MVP (1차 — 이 문서의 대상)
- 혼자 쓰는 경험만. **서버·계정 없음, 전부 로컬에서 완결.**
- 바탕화면을 돌아다니는 펫 + 건강 알림 + 다마고치 생애주기(성장·죽음).
- 건강 기능 우선순위:
  - **위주**: 복약지도(처방약 + 영양제), 물 마시기
  - **보조**: 스트레칭·자세, 눈 휴식·수면

### 비범위 (2차 이후 — 지금 만들지 않음)
- 친구와 **교배/교류** 등 온라인 소셜 기능 (계정·서버·매칭 필요).
- 단, MVP에서 펫 데이터를 **내보내기/불러오기(파일)** 가능하게 설계해 2차 확장 대비.

## 4. 플랫폼 & 기술 스택

- **OS**: 맥(macOS) 먼저. 윈도우는 이후 확장.
- **프레임워크**: Electron + React (포트폴리오의 Next.js/React 자산 재활용).
- **빌드**: Vite 기반(electron-vite 또는 Electron Forge).
- **로컬 저장**: 가벼운 파일 DB(electron-store로 시작, 필요 시 SQLite로 이전).
- **애니메이션**: 스프라이트시트 또는 Lottie 등 — 포폴 퀄리티의 귀여운 펫.

## 5. 아키텍처 — 두 개의 창 + 트레이

### 5.1 펫 오버레이 창
- 프레임 없음 / 배경 투명 / 항상 위(always-on-top).
- 마우스 클릭은 기본 통과(click-through), **펫 몸통 영역만** 클릭·드래그 가능.
- 화면을 자유롭게 돌아다니고(주로 아래·가장자리), 알림 시 반응.

### 5.2 컨트롤 패널 창
- 일반 창. 복약/영양제·물 목표 설정, 펫 상태·스트릭 확인.
- 펫의 컨텍스트 메뉴 또는 트레이 아이콘에서 연다.

### 5.3 메뉴막대(트레이) 아이콘
- 패널 열기 / 펫 잠깐 숨기기 / 종료. 평소엔 트레이에 상주.

### 5.4 라이프사이클
- 로그인 시 자동 실행(시작프로그램 등록).
- 방해금지 시간(밤): 알림·과한 움직임 자제(수면 알림은 예외 가능).

## 6. 상호작용 (Interaction)

- **드래그**: 펫을 클릭한 채 끌어 원하는 위치로 이동.
- **옵션/컨텍스트 메뉴**: 펫을 **길게 누르기** 또는 **마우스 오른쪽 버튼** →
  메뉴 표시(예: 패널 열기, 먹이/물 주기, 숨기기, 설정, 종료).
- **알림 응답**: 펫 옆 말풍선의 "먹었어요 / 나중에" 버튼, 또는 맥 네이티브 알림.

## 7. 데이터 모델 (로컬)

- **펫**: 이름, 외형(스킨), 성장단계(알→아기→성체), 스탯{건강, 행복, 기력},
  생일, 마지막 먹은 시각, 마지막 마신 시각, 생존 상태.
- **복약/영양제**: `[{ 이름, 영양제여부, 복용시간[], 요일[], 용량 }]` + 복용 기록 로그.
- **물**: 하루 목표 컵 수 + 마신 시각 로그.
- **보조 알림 설정**: 스트레칭·눈휴식·수면 주기, 방해금지 시간대.
- **설정**: 자동 실행, 알림 방식 등.
- **내보내기/불러오기**: 펫 데이터를 파일로 직렬화 (2차 교배 대비 시드).

## 8. 알림 엔진

- 백그라운드에서 주기적으로(예: 1분 간격) 점검:
  - 복약/영양제 복용 시간 도래 여부
  - 물 섭취 주기 / 하루 목표 진척
  - 스트레칭·눈휴식·수면 주기
- 도래 시 동작:
  1. 펫이 반응(알약 들어보임 / 목말라함 / 졸려함 등)
  2. 맥 네이티브 알림 + 펫 옆 말풍선("먹었어요 / 나중에")
  3. 사용자가 확인 → 기록 + 펫 스탯 상승
  4. 계속 무시 → 스탯 점진 감소(아래 생애주기로 연결)

## 9. 다마고치 코어 — 생애주기 & 죽음

- **스탯 감소·회복**: 시간이 지나면 스탯 자연 감소, 건강습관 이행 시 회복.
- **외형 매핑**: 건강하면 활발·장난스럽게 / 방치하면 처지고 시들시들·아파 보임.
- **성장·진화**: 연속 달성(스트릭)이 쌓이면 성장단계 진행, 새 외형·소소한 보상 해금.
- **죽음(경각심 장치)**: 장기 방치 시 단계적으로 악화 →
  1. **아픔**: 외형 변화, 부드러운 경고
  2. **위독**: 명확한 시각 변화 + 긴급 알림("펫이 위독해요")
  3. **죽음**: 끝까지 방치 시 사망
- **사후 재시작**: 죽으면 **추모(메모리얼)** 후 **새 알에서 다시 시작**.
  강제성·경각심은 살리되, 영구적 막힘은 없게.

### 펫 동작 상태기계
- 상태: 가만히 / 걷기 / 잠자기 / 먹기 / 마시기 / 축하 / 슬픔 / 아픔 / 위독.

## 10. 검증 (Testing)

- **순수 로직(알림 스케줄러, 스탯 감소·회복, 생애주기 전이)**: 화면과 분리된
  순수 함수로 구현하고 **테스트 우선(TDD)**.
- **오버레이 동작(투명창, click-through, 드래그, 컨텍스트 메뉴)**: 수동·시각 확인.

  (현재는 경과 시간 기준. 돌봄에 따른 성장 분기는 플랜 3 건강기능과 연결.)
